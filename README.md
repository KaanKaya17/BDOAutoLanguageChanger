# BDO Türkçe Yama

Black Desert EU için minimal Türkçe dil güncelleme aracı.

## İndir

[Tek EXE indir](https://github.com/KaanKaya17/BDOAutoLanguageChanger/releases/latest/download/BDOTurkceYama.exe) · [Tüm sürümler](https://github.com/KaanKaya17/BDOAutoLanguageChanger/releases)

Windows x64. MENA ve .NET kurulumu gerekmez.

## Kullanım

1. Oyunu ve başlatıcıyı kapat.
2. **Dosya seç** ile EU oyunundaki `ads/languagedata_en.loc` dosyasını seç.
3. **Güncelle** düğmesine bas; oyunda İngilizce dilini kullan.

Güncel Türkçe dil dosyası MENA indirme sunucusundan alınır; önceki dosya yedeklenir. İşlem sırasında **İptal et** ile durdurulabilir. Yedekler Windows yerel kullanıcı verisindeki `BDOHelper/turkce-yama` klasöründe korunur.

Yeni uygulama sürümü olduğunda durum satırında bildirilir. Yüklemek için bildirime tıklanır; paket yayın anahtarı imzası ve SHA-256 ile doğrulanır. Önceki uygulama sürümü korunur. Bu imza Windows Authenticode sertifikası değildir.
